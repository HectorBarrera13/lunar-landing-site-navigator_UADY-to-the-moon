### 2026-11-14 — Base architecture initialization

- **Agent:** opencode (big-pickle)
- **Requested task:** Initialize the base structure, dependencies, and Agent-Ready documentation for the 3D Solar System.
- **Setup description:**
  - Manual scaffold of Vite 8 + React 19 + TypeScript in strict mode.
  - Tailwind CSS v4 integrated through `@tailwindcss/vite`, without `tailwind.config.js` or manual PostCSS configuration.
  - 3D dependencies installed: `three`, `@react-three/fiber`, and `@react-three/drei`.
  - Zustand installed as the shared state manager.
  - `@/` alias pointing to `src/` in TypeScript and Vite.
  - Base folders created for the `ui/` and `canvas/` layers, plus `store/`, `data/`, `lib/`, `types/`, `public/models/`, and `public/textures/`.
  - Agent-Ready documentation created: `AGENTS.md`, `AI_LOG.md`, and `ARCHITECTURE.md`.
- **Initial technical decisions:**
  - **Vite over Next.js:** the application is an interactive WebGL SPA; this avoids SSR friction and the non-SSR `dynamic imports` that the Canvas would require in Next.js App Router.
  - **Zustand over React Context:** enables granular selectors and transient subscriptions, reducing re-renders of the 3D tree in the animation loop.
  - **Tailwind v4:** native Vite integration and design tokens through `@theme` in `src/index.css`.
  - **TypeScript `~5.9.3`:** TypeScript 7.x is avoided to maximize compatibility with the React Three Fiber type ecosystem.
  - **npm:** `package-lock.json` lockfile for universal reproducibility.
  - **No tests or CI/CD:** out of scope per project restrictions.
- **Installed versions:**
  - Runtime: `react@19.3.1`, `react-dom@19.3.1`, `three@0.187.0`, `@react-three/fiber@9.8.2`, `@react-three/drei@10.7.9`, `zustand@5.1.0`.
  - Dev: `vite@8.3.8`, `@vitejs/plugin-react@6.3.0`, `tailwindcss@4.3.5`, `@tailwindcss/vite@4.3.5`, `typescript@5.9.3`, `@types/react@19.3.0`, `@types/react-dom@19.3.0`, `@types/three@0.187.0`, `@types/node@22.20.5`.
- **Files created:**
  - Configuration: `.gitignore`, `.nvmrc`, `index.html`, `package.json`, `vite.config.ts`, `tsconfig.json`, `tsconfig.app.json`, `tsconfig.node.json`, `package-lock.json` (generated by npm).
